## Установка и запуск

Откройте терминал и выполните следующие команды:

### 1. Клонирование репозитория
```bash
git clone https://github.com/Tgalochka05/Game_Boom_Cat.git
cd Game_Boom_Cat
```

### 2. Настройка переменных окружения
Так как файл с паролями `.env` скрыт из репозитория в целях безопасности, создайте его вручную:

1. Создайте файл с именем `.env` в корне проекта (рядом с `docker-compose.yml`).
2. Вставьте в него следующий код:
```env
POSTGRES_DB=gamedb
POSTGRES_USER=gameuser
POSTGRES_PASSWORD=supersecretpassword
DB_HOST=db
```

### 3. Запуск контейнеров
Сборка и запуск проекта в фоновом режиме:
```bash
# Для Linux (Red OS/Ubuntu) может потребоваться sudo
docker-compose up -d --build
```
*Если вы на Windows, `sudo` писать не нужно.*

### 4. Применение миграций
Создаем таблицы в базе данных внутри контейнера:
```bash
docker-compose exec web python manage.py migrate
```

### 5. Создание администратора
Чтобы попасть в админ-панель, создайте суперпользователя (придумайте логин и пароль):
```bash
docker-compose exec web python manage.py createsuperuser
```

## Как проверить работу (Демонстрация)

После запуска проект доступен по адресу: **http://localhost:8000**

### 1. Игра и Пользователи
1.  Откройте **http://localhost:8000**.
2.  Зарегистрируйтесь (кнопка "Регистрация") или войдите под созданным пользователем.
3.  Сыграйте одну игру, чтобы результат сохранился в БД.
4.  Нажмите "Таблица лидеров" — данные подтягиваются через API.

### 2. Административная панель
1.  Перейдите по адресу **http://localhost:8000/admin/**.
2.  Войдите под суперпользователем (которого создали в шаге 5).
3.  **Доступные функции:**
    *   Просмотр пользователей (`User profiles`).
    *   Просмотр и редактирование игр (`Game sessions`).
    *   Управление достижениями (`Achievements`).
    *   и т.д.

### 3. Экспорт в Excel (XLSX)
1.  В админке зайдите в раздел **Game sessions**.
2.  Поставьте галочки напротив нескольких игр.
3.  В выпадающем списке "Action" (Действие) выберите **"Экспорт выбранных в XLSX"**.
4.  Нажмите **Go** — файл скачается автоматически.

### 4. Работа с API
Весь функционал доступен через REST API (автодокументация DRF):
*   Главная API: **http://localhost:8000/api/**
*   Таблица лидеров (с фильтрацией): **http://localhost:8000/api/leaderboard/?level=1**
*   Профиль пользователя: **http://localhost:8000/api/users/me/**
*   **http://localhost:8000/swagger/**

Также перед использованием в продакшн не забудьте скопировать все статические файлы через команду: 
```bash
docker-compose exec web python manage.py collectstatic --noinput
```

